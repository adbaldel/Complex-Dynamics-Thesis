# Dynamics of Möbius transformations

`main.tex` is a self-contained exposition of fixed points, multipliers,
conjugacy normal forms, dynamical classification, matrix trace criteria,
and worked examples. It does not import any other repository documents.

From this directory, compile with:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The result is `main.pdf`. Standard TeX Live packages are sufficient.
